# API 参考

以下接口仅用于文档展示，不提供真实服务。

## 查询文档列表

- 请求方法：GET
- 请求路径：/api/docs
- 功能：返回文档条目列表。

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"}
  ]
}
```

## 查询单篇文档

- 请求方法：GET
- 请求路径：/api/docs/{id}
- 功能：根据 id 返回单篇文档详情。

### 参数说明

| 参数 | 位置 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- | --- |
| id | 路径 | 整数 | 是 | 文档条目的唯一编号 |

### 错误码示例

```json
{
  "error": {
    "code": 404,
    "message": "document not found"
  }
}
```
